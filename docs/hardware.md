# Hardware Specifications & Nature Probe Interface

## Core Platform: iQOO 15
- **Chipset**: Qualcomm Snapdragon 8 Elite Gen 5
- **RAM**: 16 GB LPDDR5X
- **Audio ADC**: 24-bit / 48kHz Multi-channel Microphone Array

## Optional Nature Probe Extension
- **Interface**: USB-C OTG (Audio Class 2.0)
- **Sensor 1**: Piezoelectric contact microphone (for stem and leaf vibrations)
- **Sensor 2**: Ultrasonic MEMS acoustic transducer (effective range 18 kHz - 96 kHz)
