# Privacy, Security, and Local Processing

- **On-Device First**: All real-time audio and video frames are analyzed in volatile RAM buffers.
- **No Surreptitious Recording**: Microphone ingestion is active only during NATURA LIVE or explicit recording.
- **Human Voice Suppression**: Bioacoustic filters aggressively de-emphasize human speech frequencies to protect bystander privacy.
- **Location Control**: GPS coordinates are attached to Nature Moments solely upon explicit user permission.
