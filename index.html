Native Phone Installation

How to Install NATURA as a Mobile App

🤖

Android (Chrome, Edge, Samsung)

  1. Open https://natura-hgb4.onrender.com in Chrome.
  2. Tap the "📲 Install App" button at the top banner (or browser menu ⋮ → Install App).
  3. Tap "Install". Android compiles a native WebAPK that runs full-screen without browser bars.
🍎

iPhone & iPad (Safari)

  1. Open https://natura-hgb4.onrender.com in Safari.
  2. Tap the Share button (📤 / ⎋) at the bottom toolbar.
  3. Scroll down and tap "Add to Home Screen" (➕), then tap Add in the top right.
  4. NATURA is now on your home screen and launches in standalone full-screen mode!
📦

Standalone APK Package (.apk)

  1. Visit PWABuilder.com.
  2. The tool will automatically package NATURA's live manifest.
  3. Click "Package for Android" to download a signed app-release.apk package to install on any phone.
